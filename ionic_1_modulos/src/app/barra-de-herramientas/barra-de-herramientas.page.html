Barra ded herramientas

Las barras de herramientas suelen ubicarse encima o debajo del contenido y proporcionan contenido y acciones para la pantalla actual. Cuando se colocan dentro del contenido , las barras de herramientas se desplazan junto con este. Las barras de herramientas pueden contener varios componentes diferentes, como títulos, botones, iconos, botones de retroceso, botones de menú, barras de búsqueda, segmentos, barras de progreso y más.

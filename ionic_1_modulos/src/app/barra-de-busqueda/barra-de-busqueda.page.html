Barra de busqueda

Las barras de búsqueda representan un campo de texto que permite buscar en una colección. Pueden mostrarse dentro de una barra de herramientas o en el contenido principal. Se recomienda usar una barra de búsqueda en lugar de un campo de entrada para buscar en listas.

Lista

Las listas se componen de varias filas de elementos que pueden contener texto, botones, interruptores, iconos, miniaturas y mucho más. Generalmente, las listas contienen elementos con contenido de datos similar, como imágenes y texto. Las listas admiten varias interacciones, como deslizar elementos para ver opciones, arrastrar para reordenar elementos dentro de la lista y eliminar elementos.

Menu

El componente de menú es un panel de navegación que se desliza desde el lateral de la vista actual. Por defecto, utiliza el lado de inicio, deslizándose desde la izquierda para la lectura de izquierda a derecha (LTR) y desde la derecha para la lectura de derecha a izquierda (RTL), pero este lado se puede modificar. El menú se mostrará de forma diferente según el modo de lectura; sin embargo, el tipo de visualización se puede cambiar a cualquiera de los tipos de menú disponibles. El elemento de menú debe ser un elemento hermano del elemento de contenido raíz. Puede haber cualquier número de menús adjuntos al contenido. Estos se pueden controlar desde las plantillas o programáticamente usando el MenuController.
